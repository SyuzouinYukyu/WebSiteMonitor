# 📘 WebSiteMonitor 取扱説明書

WebSiteMonitor v1.0.4 の基本操作と、誤検知を減らすための設定方法を説明します。

## 🚀 1. 起動

`WebSiteMonitor_v1.0.4.exe` を書き込み可能な任意のフォルダーへ配置して起動します。

初回起動後、EXE と同じ場所に `data` フォルダーが作成されます。WebSiteMonitor はポータブル運用を前提としており、書き込みできない場合に AppData へ勝手に切り替えません。

## ➕ 2. サイトを追加する

メイン画面の **「追加」** を押します。

主な設定項目:

- 🏷️ **サイト名** — 一覧に表示する分かりやすい名前
- 🌐 **URL** — 監視するページまたは Feed
- 🧭 **ブラウザー互換User-Agent** — 通常取得で 403 Forbidden になる場合のみ ON
- 🎯 **監視方式** — 自動 / RSS・Atom / ページ全体 / テキスト / CSS / XPath / 正規表現
- ⏱️ **スケジュール** — 一定間隔 / 毎日指定時刻 / 手動
- 🔔 **通知** — Windows通知 / 独自ポップアップ / 通知サウンド

設定後は、保存前に **「監視テスト / 抽出プレビュー」** を実行することを推奨します。

## 🎯 3. 監視方式の選び方

| 監視方式 | 用途 |
|---|---|
| 🤖 自動 | RSS / Atom を自動検出し、利用できない場合は本文テキストへフォールバック |
| 📡 RSS / Atom | Feed が明示されているサイト |
| 🧱 ページ全体 | HTML 全体の変化を監視したい場合 |
| 📄 テキスト | ページ本文の文字列変化を監視したい場合 |
| 🎨 CSS | CSS Selector で特定要素だけを監視 |
| 🧭 XPath | HTML構造から特定要素だけを正確に監視 |
| 🔎 正規表現 | 特定パターンだけを抽出して監視 |

広告・ランキング・日付・おすすめ表示などが頻繁に変わるサイトでは、ページ全体や本文テキストより **XPath / CSS / 正規表現** が適しています。

## 🛡️ 4. 403 Forbidden が出る場合

サイト側が一般的なツールの User-Agent を拒否している場合があります。

そのサイトだけ **「ブラウザー互換User-Agentを使用する」** を ON にして再度「監視テスト / 抽出プレビュー」を実行してください。

この機能はサイトごとの明示設定です。全サイトへ自動適用しません。

## 📢 5. 広告の変化を更新として検知する場合

広告や動的コンテンツの変化は、ページ全体・本文テキスト監視では更新として認識される場合があります。

対処方法:

1. 🔎 「監視テスト / 抽出プレビュー」で本当に必要な情報を確認します。
2. 🎯 XPath または CSS Selector に切り替えます。
3. 🧩 バージョン番号や更新日時など、必要部分だけを抽出します。
4. ✅ プレビュー結果に広告文が含まれないことを確認して保存します。

## ⏰ 6. スケジュール

**一定間隔**では指定した分数ごとに確認します。**毎日指定時刻**では1日1回、設定時刻に確認します。

「今すぐ確認」では選択サイトを手動確認し、「全て確認」では有効な監視対象をまとめて確認できます。

## 🔔 7. 通知

更新検出時には、必要な通知方法を組み合わせて使用できます。

- 🪟 Windows通知
- 💬 独自ポップアップ
- 🔊 通知サウンド

通知音は「テスト再生」で事前確認できます。FFmpegが必要な形式でも、待機中にFFmpegは常駐しません。

## 🔤 8. 文字サイズ

GUIフォントは **10～18pt** の範囲で変更できます。

- `Ctrl + マウスホイール`
- 非スクロール領域でのマウスホイール

DataGridViewなど通常スクロールが必要な場所では、スクロール操作を優先します。設定した文字サイズは次回起動時も保持されます。

## 🗃️ 9. 保存データ

WebSiteMonitor のユーザーデータは EXE と同じ場所の `data` フォルダーへ保存されます。

- ⚙️ `settings.json` — アプリ設定
- 🗄️ `WebSiteMonitor.db` — サイト設定・更新履歴
- 📝 `logs` — ログ
- 🔊 `sounds` — 必要に応じた音声ファイル
- 🧰 `cache` — FFmpeg等の実行時キャッシュ

バックアップする場合は、WebSiteMonitorを終了してから `data` フォルダー全体をコピーする方法が確実です。

## 🧯 10. トラブルシューティング

### 403 Forbidden
🧭 ブラウザー互換User-Agentを対象サイトだけONにして再テストします。

### 更新していないのに通知される
🎯 広告や動的部分が変化していないか確認し、XPath / CSS / 正規表現で対象範囲を絞ります。

### 通知音が鳴らない
🔊 ファイルパス、音量、形式を確認し、「テスト再生」で結果を確認します。音声だけの失敗でサイト監視自体は停止しません。

### セキュリティソフトが警告する
🛡️ 配布元と SHA-256 を確認してください。v1.0.4 正規ビルドのSHA-256は README に記載しています。セキュリティソフト全体を無効化する運用は推奨しません。

## 🔐 11. プライバシー

WebSiteMonitor はテレメトリや利用状況送信を行いません。監視URL・履歴・設定・ログはローカル保存です。

GitHubの公開ソースには、実利用時の `data`、監視URL一覧、履歴、ログ、通知音、秘密情報を含めていません。
