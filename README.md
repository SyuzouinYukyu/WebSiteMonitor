# 🌐 WebSiteMonitor v1.0.4

**WebSiteMonitor** は、Windows 11 x64 向けの軽量なウェブサイト更新監視ツールです。タスクトレイに常駐し、指定したウェブページや RSS / Atom Feed を定期確認して、更新を検出すると Windows 通知・独自ポップアップ・通知音で知らせます。

## ✨ 主な機能

- 📡 RSS 2.0 / Atom の監視と自動 Feed 検出
- 📄 ページ全体・本文テキストの監視
- 🎯 CSS Selector / XPath / 正規表現による部分監視
- 🧭 サイト単位のブラウザー互換 User-Agent
- 🕒 一定間隔・毎日指定時刻・手動確認
- 🔔 Windows 通知・独自ポップアップ・通知音
- 🗃️ SQLite による更新履歴管理
- ⚡ ETag / Last-Modified / 304 Not Modified 対応
- 🧰 タスクトレイ常駐・単一インスタンス・Windows 自動起動
- 🔎 監視テスト / 抽出プレビュー
- 🔤 GUI フォントサイズ 10～18pt の変更・保存
- 📦 ポータブル運用（AppData への自動退避なし）

## 💻 対応環境

- Windows 11 x64
- .NET 10
- Release版は win-x64 / self-contained / single-file

## 🚀 使い方

詳しい操作方法は **[📘 取扱説明書](docs/USER_GUIDE.md)** を参照してください。

基本操作は次のとおりです。

1. ➕ **追加** からサイト名と URL を登録します。
2. 🎯 **監視方式** を選択します。迷う場合は「自動」または「テキスト」から始めます。
3. ⏱️ **スケジュール** と確認間隔を設定します。
4. 🔔 Windows通知・独自ポップアップ・通知サウンドから必要な通知方法を選びます。
5. 🔎 **監視テスト / 抽出プレビュー** で監視対象が意図どおりか確認してから保存します。

## 🛡️ 403 Forbidden になるサイト

通常の HTTP 取得を拒否するサイトでは、サイト編集画面の

**「ブラウザー互換User-Agentを使用する」**

を必要なサイトだけ ON にできます。既定は OFF です。

この機能は JavaScript を実行するブラウザーエンジンではありません。WebView2 / Playwright は使用せず、HttpClient ベースの軽量な取得方式を維持しています。

## 🎯 広告などで誤検知する場合

ページ内の広告・おすすめ欄・日時表示などが頻繁に変化するサイトをページ全体で監視すると、目的の更新ではない変更を検知することがあります。

その場合は **XPath / CSS Selector / 正規表現** を使い、バージョン番号や更新情報など必要な箇所だけを監視してください。これにより広告等の変動を監視対象から除外できます。

## 🔊 通知音

通知音は MP3 / AAC / M4A / FLAC / WAV / WMA / OGG / OPUS / AIFF / AC3 / APE / WavPack / MIDI など多数の形式に対応します。

FFmpeg が必要な形式では、通知音再生時だけ FFmpeg を起動します。待機中に FFmpeg / decoder / MIDI device を常駐させません。DRM の解除・回避は行いません。

## 📁 ポータブルデータ

実行時データは EXE と同じ場所の `data` フォルダー以下に保存します。

```text
data/
├─ settings.json
├─ WebSiteMonitor.db
├─ logs/
├─ sounds/
└─ cache/
```

これらはユーザー固有データを含む可能性があるため、本リポジトリでは `.gitignore` により Git 管理対象外としています。

## 🧪 テスト

v1.0.4 は、既存の回帰テストを含む **115件の自動テスト（失敗0 / スキップ0）** を通過した状態で作成されています。

主な検証対象:

- User-Agent / 403 応答 / Schema 4 migration
- `MonitorRevision` による stale result 破棄
- DataGridView の可変レイアウト
- FFmpeg PCM short-read / 連続再生
- FIFO 通知音キュー
- RSS / Atom / charset / Retry-After
- Font Zoom / DPI / UI レイアウト
- Windows 統合
